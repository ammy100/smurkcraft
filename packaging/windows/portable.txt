Smurkcraft portable mode

While this file sits next to smurkcraft.exe, Smurkcraft keeps its preferences, brush presets,
crash-recovery autosaves and startup state in the SmurkcraftData folder beside it, and writes
nothing to %APPDATA%. Copy the whole folder to move Smurkcraft with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\Smurkcraft) instead.
If SmurkcraftData can't be written (for example on a read-only drive), Smurkcraft says so and
uses %APPDATA%\Smurkcraft instead.
